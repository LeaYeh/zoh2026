ZOH 2026 · Track #1 Industrial AI — Pipeline Architecture

Infineon · Process Sequence Modeling · GPT-2 from scratch · 3 Submission Tasks · Leonardo A100 Cluster

Model Architecture

  • • GPT-2 style transformer — trained from scratch
  • • Custom vocabulary: all unique process step names
  • • n_embd=256 · n_layer=6 · n_head=8 · ~2.5M params
  • • n_positions=256 — covers 115–150 step sequences
  • • Causal LM loss — next-token prediction objective
  • • PAD tokens masked (labels=−100, attn_mask=0)
  • • Stretch: n_embd=512, n_layer=8 for scaling ablation

Submission Tasks

  • • Task 1 — Next-Step: Top-1/3/5 Accuracy, MRR
  • • Task 2 — Completion: Exact Match, Edit Distance, Token Acc
  • • Task 3 — Anomaly: perplexity → F1, ROC-AUC, Rule Attribution
  • • Eval set fixed & shared — all teams use same files
  • • Task 4 (OOD, organiser-only): 4th family, post-submission
  • • 3 families: IC · IGBT · MOSFET · 115–150 steps/seq

Infrastructure & Workflow

  • • Training: Leonardo cluster · 64× NVIDIA A100 (BF16)
  • • Data: 3K pre-generated seqs + unlimited via generate_sequences.py
  • • WandB: sole source of truth — every run logged
  • • Entry: uv run python src/train.py configs/exp/<name>.yaml
  • • Demo: uv run python app/demo.py → :7860
